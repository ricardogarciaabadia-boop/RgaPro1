# Mi cartera Ocaso — proyecto Android privado

Proyecto Android preparado para generar un APK privado.

Características base:
- APK sin publicar en Google Play.
- Pantalla única del prototipo.
- Acceso biométrico del sistema Android.
- Cámara/documentos (la integración avanzada de OCR/IA y servidor se implementará en la siguiente fase).
- Sincronización con servidor privado pendiente de configurar.

## Importante
En este entorno no está instalado Android SDK/Gradle, por lo que no puedo compilar aquí el APK firmado. El proyecto sí está preparado para abrirse en Android Studio y generar el APK.

Para datos reales todavía debe completarse el backend privado, cifrado de documentos y sincronización segura.
