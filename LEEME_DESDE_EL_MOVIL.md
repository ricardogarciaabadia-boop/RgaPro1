# RgaPro — instalación desde el móvil

## Parte A: subir el proyecto
1. Descarga el ZIP de RgaPro.
2. En GitHub abre el repositorio privado RgaPro.
3. Pulsa Add file > Upload files.
4. Selecciona todos los archivos y carpetas del ZIP.
5. Pulsa Commit changes.

## Parte B: compilar
1. Pulsa Actions.
2. Pulsa "RgaPro - Generar APK".
3. Pulsa "Run workflow".
4. Pulsa de nuevo el botón verde "Run workflow".
5. Espera hasta ver una marca verde.

## Parte C: descargar
1. Abre la ejecución que acaba de terminar.
2. Baja hasta "Artifacts".
3. Pulsa "RgaPro-APK".
4. Descarga el ZIP.
5. Abre el ZIP y abre RgaPro.apk.
6. Android puede pedir permiso para instalar desde esta fuente. Permítelo para el navegador/gestor de archivos que estés usando.
7. Pulsa Instalar.

## Si aparece una X roja
No intentes corregir nada. Haz una captura de pantalla de la pantalla del error y envíamela.

## Seguridad
Mantén el repositorio privado. Nunca subas clientes, pólizas, contraseñas, tokens,
claves de cifrado o certificados/keystores.
Este APK es de prueba (debug), no es todavía la versión de Google Play.
