# OCR Fase 1 — DNI/NIE

Alcance único de esta fase:

- Mantener intacta la interfaz y el resto de la aplicación.
- Modificar únicamente el comportamiento del OCR dentro del acceso DNI.
- Leer anverso y reverso.
- Extraer únicamente: nombre y apellidos, DNI/NIE, fecha de nacimiento, dirección, teléfono y email.
- Todos los datos deben quedar editables.
- Combinar la información de anverso y reverso antes de presentar el resultado final.
- Guardar el resultado del DNI y, en una fase posterior, relacionarlo con el cliente correspondiente.

No se modifican pólizas, documentos generales, menús, autenticación, biometría ni otras pantallas.
